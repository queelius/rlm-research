# Published RLM8B: intended-interface reachability reference

Design for MAIN review, 2026-09-10. CPU acquisition/inspection only; no implementation, GPU, service, environment installation, or launch authorization. The brainstorming review materially changed the recommendation from cached-current scaffold to a historical FINAL-compatible scaffold.

## Decision and question

Recommend **24 paired tasks × two 8B policies = 48 endpoints**, before another small local SFT recipe. Can the published RLM8B package acquire semantic evidence from real records, execute query-sensitive reduction, and finish with correct **nonzero** answers under its intended interface? Compare to Qwen3-8B in exactly the same scaffold. This is a reference for our reachability bottleneck, not a causal comparison to earlier 4B percentages, a long-context benchmark replication, or proof that size rather than training matters.

Each policy serves both root and plain-LM subcalls; only one 8B model resides on the A10040GB at a time. Thus the treatment changes the **root-and-leaf weight package**, not root weights alone. No fixed c32, typed semantic child grammar, authored acquisition, label map, or mandatory call is supplied. A later fixed-leaf comparison would be a different experiment.

## Bounded implementation, not a new framework

Use historical `RLM.completion`, `LocalREPL` semantics, `LMHandler`, parser and logger. Prefer running that whole CPU worker **inside the already qualified rootless image/runtime**, not host LocalREPL. Existing allocation wrapper is `sidecars/runtime-an27-5780-v1/bin/docker`, image `8cfe5976b347e0201e52035256537a7cc90fca5004a0bf48cbd42b282498838c`; its private store belongs to allocation5780 and must not be migrated or cleaned. A harmless `unshare --user --map-root-user --mount --pid --fork --net true` succeeded on an27. Therefore absence of Docker in ordinary PATH is not a blocker by itself.

Preferred qualification route: one job-owned container with no host network, no project/home/secrets/model mounts, read-only inspected source/dependencies and task bytes, writable ephemeral state, and a single mounted Unix-domain inference socket. The outside collector owns authentic request/response/token checkpoints. A small explicit client adapter can use an HTTP Unix-socket transport; internal official root↔leaf sockets remain container-local. This route is **not yet qualified**. Process-isolated IPython alone is not a filesystem/security sandbox. Historical DockerREPL is a less attractive shortcut: it installs packages at startup, binds a host-loopback proxy while advertising host-gateway access, serializes state, and launches exec without a timeout. Do not blindly invoke it.

Minimum external code: immutable panel/plan; exact custom-prompt materialization; explicit-path official import and small capped/logged OpenAI client; outside raw/native ledger; container worker/owner; strict scorer. Historical OpenAIClient omits sampling arguments and enables SDK default retries: the adapter must supply frozen sampling/seeds/caps and disable retries. Suppress `_default_answer`'s extra final-answer request at iteration exhaustion; record a no-final termination instead. This is a declared cap/termination deviation, not an answer repair. No decoder or semantic transport intervention.

Proposed common sampling: temperature .6, top_p .95, top_k20, min_p0, no penalties; root8192 and child4096 output caps, no guided grammar. The [Qwen card](https://huggingface.co/Qwen/Qwen3-8B) recommends these stochastic settings for thinking mode, but the common released template is distinct; this is an explicitly chosen bounded operating point, not claimed exact paper sampling. Cap 12 root turns, 36 physical child calls, 48 total requests per endpoint, 120s hard endpoint deadline, two concurrent endpoints. Preserve over-cap requests as denied attempts, not executed calls; no prompt truncation/compaction.

One BF16 8B model, context32768, max_num_seqs2, max_num_batched_tokens4096, GPU utilization .85; no LoRA, quantization or YaRN. Approximate weights15.3GiB plus BF16 KV4.5GiB per full 32k sequence leaves a plausible 40GB margin; GPU fit is not CPU-proven. **3600s outer = 3330 work +150 cleanup +120 outer margin**. Work reserves 1620s per policy (including startup/release; 12 waves ×120s plus180s lifecycle), then90s finalization. Advance early; do not wait out reservations. Preserve the second policy reservation even if first fails. This is a one-hour maximum, not a measured runtime forecast.

## Measurements and decision rule

Prewrite all48 NULL rows. Primary strict correct /24 per policy, paired signs and eight context clusters; highlight correct nonzero /23 and zero /1. Authenticate every returned model body, served weights, request fields and token identity; FINAL_VAR additionally requires its actual retrieval observation. Authentic malformed finals are observed strict0. A capped response with complete legal final is scored and flagged. Missing finals remain endpoint NULL, with separate transport versus policy-loop/context/cap reasons, bounds, and a conservative planned-denominator operational0 view.

Independently classify actual source inspection, actual child requests and returned semantic evidence, executed accumulation/filter/operator reduction, and final dependence on those results. Mere function names, proposed code, hardcoded literals or a lucky zero are not acquisition/reduction. Wrong child predictions stay wrong; report dataset correctness separately from consistency with observed predictions when recoverable. Keep failed programs, all physical calls/tokens/cache/elapsed/cap reasons and unknown cost fields; provider billing unknown. Checkpoint each call and episode; resume may harvest completed artifacts only, never reroll a planned endpoint.

Promote reachability only after several **nonzero, source-grounded executed successes across contexts**, not more valid FINAL tags. If both policies succeed, our 4B/scaffold package was a poor general capability reference. If only RLM succeeds, prioritize intended-interface transition training while retaining the root+leaf confound. If both fail with valid acquisition but bad reductions, probe task/state semantics; if failures are format/cap dominated, qualify that interface before inferring model incapacity. No direct baseline or additional arm in this first run.
