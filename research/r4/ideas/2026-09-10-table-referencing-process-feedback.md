# Table-referencing critics: useful target, not an exact reward transplant

Decision: borrow the separation of evidence fidelity from final correctness, **not** an unvalidated learned critic or immediate rejection-sampling loop. Our root can fail to acquire evidence, faithfully use a wrong child prediction, or misuse correct evidence; these need different labels.

The headline+11.96 points is gold-assisted Distill-Qwen/TableBench rejection sampling; no-gold Critic-4B gives+6.89 there and+0.26–1.11 for Qwen3-8B. ## Application to our actual bottleneck — design inference only

Use a three-part ledger: (1) acquired-state authenticity/availability; (2) fidelity to that actual state, including scoped membership, complete evidence and arithmetic; (3) final accuracy against dataset labels. A reduction faithfully using an incorrect acquired label is a source-prediction failure, not a referencing error. A copied subset missing genuine records is a use failure even if a zero answer happens to match gold. Code mentions or attractive prose do not establish execution. A no-citation segment is **unevaluated evidence use**, never affirmative progress.

Where IDs, map entries and arithmetic have exact retained observations, use deterministic membership/value checks. Open-ended intent, semantic scope interpretation and missing observations can remain adjudicated/unknown; do not claim a general exact Python verifier or reexecute sampled code. Learned critics may eventually prioritize human review, but must first be calibrated on authentic local errors. A judge conditioned on dataset gold cannot be slipped into evaluation-time actor feedback or candidate selection.

Smallest useful next step is a bounded CPU validation set from already completed traces: predeclare24 decision points spanning no-acquisition, faithful-wrong-source, omissions/miscitations and arithmetic/stopping failures. Two readers annotate evidence provenance and verification limits, blinded to final correctness until the process labels are locked. Keep all disagreements and unknowns, split by source context/trajectory rather than segments. This is diagnostic, not a new generalization benchmark or critic training set selected for easy discrimination.

Only if process labels are reliable and policy initiation becomes nontrivial should a future matched intervention compare feedback with the same additional action/token budget and fixed histories. Count every extra critic/model request and rejected candidate; preserve planned episode denominators and original failures. Any actor SFT/RL using these labels is a new objective/data recipe, distinct from the running dose continuation. First require no false acceptance of no-acquisition as successful evidence use and separation of faithful wrong-map use from misuse; otherwise retire the feedback proposal. No training code, download or GPU experiment is approved by this note.
