## Findings at the scientific seams

### Free policy does not receive the operator planner or gold

[experiment.py:33](../../sidecars/adaptive-filter-pilot-v1/experiment.py) calls the
ordinary context-only task setup, writes the pure batch module/public records/plain
query, and writes operator program/config **only** when controller is not free.
The inherited Oolong setup writes context.txt only. Host gold is used to construct
the host task answer, not copied into runtime files or the prompt. The free task
is an AdaptiveTask over StrictOolongTask, not the prior ReceiptTask; no receipt
catalogue or receipt planner is incidentally installed by that inheritance.

I checked the frozen40 package descriptions:16 free packages contain exactly
batch_contract.py/context.txt/query.txt/records.json;16 all16 and8 filter16 packages
add exactly operator_program.py/operator_config.json. Every public record has
only id/text/user. The corrected005 free fixture's actual assistant tool call
asserts that both operator files are absent before calling its child. The resulting
tool observation is `1\n`, no traceback, followed by `Answer: 1`. This is stronger
evidence than only inspecting intended setup writes. Its injected root messages
are explicitly deterministic CPU fixtures, never scientific policy behavior.

The public optional example is itself an interface intervention and may shape free
behavior; the design discloses it. This is not the unchanged historical harness.

### Child contract is shared where inputs actually coincide

builds only supplied IDs plus original question text, exact historical six-label
definitions, and the strict-map request. User metadata and the parent query are
not included. Its parser rejects duplicates, missing/unknown IDs, invalid labels,
nonfinite constants and trailing text, and preserves ID-based reduction even when
returned object keys arrive in another order. It does not classify or repair.

The005 raw provider records independently compare equal **817-element full initial
child token arrays and complete sampling objects** for operator-valid and free-valid.
They include the same actual child alias. The separate filter fixture requests only
q0001, not the other user's q0002, then returns the computed count through ACP.
This tests metadata filtering itself rather than merely an all-record operator.

Scope limit: operator-only program/config files remain visible to a generic child
inside the operator runtime, while absent in free. Ordinary child tools are retained.
Exact initial prompt identity is therefore not equality of every tool-visible
state or later child trajectory. Free can use different requests, sizes, subsets,
or direct reasoning; those calls are not paired child samples. The approved design
and scientific contract now state this whole-policy distinction.

## Required interpretation of inherited retry behavior

The proposed “no API retry” wording is too strong for unchanged nano. The pinned
[engine _call_model](../../../../ARTIFACTS.md#unpublished-files "Not published: ../../../../research-cache/2026-09-08-literature/leaf-contract.7HPUr5/nano__engine.py")
at698 still invokes call_with_retries; the cached pinned client implementation at72
uses transient-error delays15/30/60/90/120 seconds. The new engine adapter changes
only the operator branch and nullable scope, not this function. Native wire capture
rejects an unexpected second native transport inside the same get_response call,
but that is not a general disablement of nano's outer retry path. Agent/Env/native
SDK retries0 must not be conflated with this layer.

This is verified **source capability**, not observed retry/inference evidence.
Idempotent interception may replay a response without another model sample, and
global/rollout caps may cancel before all delays. Record real request IDs, retry
headers, returned/error state, token usage and replay evidence before attributing
extra compute. Main has explicitly accepted the inherited behavior unchanged and
will state no study rerolls/replacements, not zero API retries. The author's
[external acceptance caveats](ADAPTIVE_FILTER_ACCEPTANCE_CAVEATS.md), read by this
reviewer, now record this and the projection-filename distinction (SHA256
`b371288e97cba682a3b9c3af7f75bcebf9d2c215a331db51337efbbed66e4ea8`).
Sealed SPEC/READY remain untouched.

## What a completed pilot could support

opportunity only when accuracy/coverage remains adequate. Evidence that free
behavior exploits it needs query-conditioned selected-record/tool/native work,
not only a correct small count or fewer child calls. Count all root inference and
child turns, retain unknown cache/usage, preserve shared global IDs, and show all4
context clusters. If failures dominate, the result addresses interface feasibility,
not learned adaptive planning. No new reward, RLVR selection, training export or
automatic continuation is authorized by this review.
