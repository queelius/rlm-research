# New-context MNLI correspondence audit

On 16 additional paired MNLI context clusters, matching requested tags scored 639/768 displayed
labels (83.20%) versus 398/768 (51.82%) for a repeated constant tag. Matching won all 16 context
pairs and every genre stratum. All 32 native outputs were available, exact-contract valid, and copied
all requested tags, so the semantic gap is not an output-validity artifact.

This is a strong breadth replication within the same MNLI source/four genres, not a new-domain or
confirmatory result. The constant control still changes output dictionary diversity as well as
correspondence. See `analyses/leaf-mnli-new-context-correspondence-live-2026-09-10/REPORT.md` for
runtime, costs, error distribution, exact exposure boundary and audit-timing correction.
