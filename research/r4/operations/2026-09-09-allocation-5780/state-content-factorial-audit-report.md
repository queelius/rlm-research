# Independent state-content factorial audit

September 9, 2026. Showing actual historical child observations strongly changed whether the fresh
root used old state, but did **not** produce a clean accuracy effect. Old predictions were used in
18/32 V1 traces versus 3/32 V0 traces; faithful old-state-to-scoped-answer execution was 16/32
versus 3/32. Yet strict planned-denominator accuracy was 15/32 with observations and 14/32 without.
This is evidence about interface-dependent uptake, not a general accuracy or persistence claim.

## Interpretation from executed traces

Observation visibility induced real correspondence use. Across V1, 15 traces reconstructed an
exact complete 16-ID old map literal. Three more used the old evidence through an ID subset or
if-ladder. Two of the 18 then failed data flow: one counted all target labels without applying the
requested users, and one generated mismatched `q001`-style lookup keys for a `q0001` map. Sixteen
therefore reached the correct scoped count implied by the supplied predictions. This classification
comes from executed code and returned observations; inline text and scalar agreement alone do not
count.

When V0 hid the observations but left files available, only three roots read the map files. All
three merged the four width-4 files and computed the supplied scoped count. Across all four cells,
12/16 width-4 traces fully combined the archived pieces: three file-based merges and nine inline
reconstructions. This shows that width-4 merging is possible; the dominant failure was choosing or
maintaining the evidence path, not an absolute inability to merge.

Producer actions had a different effect when observations were absent. P1V0 made 17 fresh child
calls in 13 rows, compared with zero in P0V0, while using old state only once. Its 9/16 versus 5/16
accuracy gain therefore mostly reflects reenacted acquisition or procedural prompting, not recovery
of the archived observations. With observations visible, adding producer actions changed accuracy
only from 7/16 to 8/16 and reduced fresh child calls from 12 to 2. That interaction is suggestive:
actions may organize visible evidence, but when evidence is absent they cue reacquisition.

Accuracy effects are heterogeneous and weak on the paired evidence. V1 versus V0 at P0 wins four,
ties nine, and loses two among 15 available pairs. At P1 it wins four, ties seven, and loses four.
P1 versus P0 at V0 wins seven, ties six, and loses three; at V1 it wins three, ties nine, and loses
two among 14 available pairs. Context-cluster patterns vary: for example P0V1 improves validation-00
from 1/4 to 3/4 but lowers validation-01 from 1/4 to 0/4. Only four previously research-exposed
contexts underlie 16 paired source states and 64 endpoints, so endpoint counts are not independent
replications.

Faithful state use and gold correctness are also different endpoints. Historical maps retain wrong
child predictions. Some correctly executed old-map reductions therefore miss dataset gold; some
heuristic or freshly reacquired paths happen to match gold. That counterevidence explains why a
large uptake contrast can coexist with a one-answer marginal accuracy difference.

Four completed responses were observed strict failures because they wrapped an answer in prose
(three P0V1, one P1V0); no repair or answer extraction was applied. Two separate endpoints, one
P0V1 and one P1V1, timed out after about 182 and 185 seconds. Each had one authenticated root model
call but no completed episode or final response, so both remain genuine NULLs rather than zeros.

## Native, provenance, and cost audit

All 196 returned native calls authenticate with no discrepancy in unique capture, routed
root/child adapter, response model, finish branch, usage, first prompt IDs, or available final
prompt/completion branch tokens. Independent strict scoring disagrees with the scientist score on
0/64 rows. There were 165 root calls and 31 new child calls, using 388,034 input tokens, 28,322
output tokens, 355,728 cached input tokens, and 32,306 uncached input tokens. Per-cell new physical
calls were 44, 66, 53, and 33 for P0V0, P0V1, P1V0, and P1V1 respectively.

The packages, binding, public data, host scoring labels, native template, states, and source cuts
are byte-identical to the pinned restart inputs. All 11 inherited pins verify, and all 64 runtime
setup attestations match the expected package, records, context, and query hashes, including the two
timed-out coordinates. These are fresh REPL/root sessions; no old kernel, later correction, final,
private child state, or gold entered a runtime package.

The same 40 historical child acquisitions are physical source work once: 37,340 input, 2,430
output, and 34,528 cached tokens. The 160 calls obtained by charging each of 64 endpoints its one or
four historical acquisitions are hypothetical standalone accounting, not new work. CPU export and
tokenization took 73.0986 seconds. The new collector took 683.4586 seconds; the owner took 728.2620
seconds and released cleanly. These timing bases overlap and are not summed.

The method was written after launch. Its seal was created while outputs were still arriving—61 row
names and 60 episode names existed—before this auditor read any scores, replies, or programs. The
terminal tree was then pinned before parsing. This is an independent post-launch exploratory audit,
not a prospective preregistration or fresh-context confirmation.

## Ranked next comparisons

1. **Promote concise observations, not historical action quotes.** On genuinely new contexts,
   compare a compact merged map with the same map injected as an initial authenticated tool return.
   Keep the exact final contract and score retrieval choice, correspondence, scoped reduction, and
   gold separately. This tests whether explicit visibility or tool-mediated state is the useful
   carrier.
2. **Add a deterministic reducer baseline.** Merge/filter/count the same historical maps in host
   code. If reliable, use the LLM for classification and avoid paying for the observed reacquisition
   and composition failures.
3. **Stratify upstream correctness before replication.** Freeze genuinely new context clusters and
   analyze correct versus deliberately corrupted/wrong prediction maps without selecting outcomes.
   This separates state uptake from the semantic quality of state. Another seed on these four
   contexts is only seed robustness.

The P1V0 result does not justify treating producer quotes as persistent state: they primarily
triggered new calls. The useful signal is that actual observations sharply increased old-state use
and reduced reacquisition when combined with actions, while gold accuracy remained limited by
upstream errors and downstream scope/correspondence mistakes.
