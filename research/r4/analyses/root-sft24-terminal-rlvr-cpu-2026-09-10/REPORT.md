## Blocking findings

1. **Native replay points to a missing script.** `warm_train.py` forwards the exact QSR `authenticate_group`. In `root-query-sensitive-rl-v1/qsr_train.py`, the authenticated replay argv uses `s.ROOT/'qsr_native.py'`. Here ROOT is the warm sidecar, where that file does not exist. `warm_native.py` also lacks the CLI. Therefore an otherwise admissible group cannot pass pre-model replay. The external reproduction extracts the command expression from the actual imported function, yielding the missing path, not a guessed command.

2. **Call-time module imports escape the alias scope.** `warm_export.py` supplies aliases only while loading QSR exporter. Its `rebuild()` later executes `from qsr_collect import verify_spec`, raising `ModuleNotFoundError` in the actual warm-owner import composition. Separately, the inherited metric's `endpoint()` begins `import qsr_native as n` and raises the same class of error. Fixing only the first import is insufficient: the complete export/native-metric/replay call graph needs the correct explicit bindings. This defect prevents ordinary endpoint export even before trainer replay.

3. **Startup alarm remains active during collection.** `warm_owner.execute()` arms the startup deadline, starts the service, then calls `collection_stage()` without re-arming. Neither that function nor the installed `suite.command` changes SIGALRM. The actual collection-stage fixture observed **179.9997 seconds remaining on the process alarm versus 2339.9998 seconds on the readout command**. Both 600-second training collection and 2340-second final collection would instead receive the remainder of the startup allowance. The fix must preserve collector/export caps and shared-stage bounds, not remove deadline enforcement.

`reproduce_v1.py` reproduces the four concrete manifestations of these three issues with no model or service execution. The alarm fixture intercepts transport/export but runs the real collection-stage body and real process timer. It does not authenticate synthetic training evidence or bypass a runtime gate.
