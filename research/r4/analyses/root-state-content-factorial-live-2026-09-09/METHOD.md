# Independent audit method

Timing: written after the 21:27:06 UTC launch. At method freeze the auditor had inspected the
frozen design, protocol, collector, plan shape, and filesystem counts (54 row files, 53 episodes),
but had not read any row outcome, reply, score, or model program. MAIN had disclosed only that 49
rows existed at an earlier moment and had not disclosed outcomes. This is a post-launch exploratory
audit, not a prospective preregistration.

The audit will inventory and hash the output tree before parsing. If the run is not terminal, it
will report the exact partial denominator and will not treat unreturned planned coordinates as
zeros. After terminal, it may add a final immutable pin and score all 64 coordinates.

Primary outcome is exact whole-strip `Answer: N` against gold independently rebuilt from public
records and scoring-only labels. A returned malformed answer is zero; a genuinely missing,
unreturned, or natively inconsistent final is NULL. Native checks cover routed adapter/model,
unique returned capture, first prompt IDs, final branch prompt/completion IDs, finish branch, message
content, and usage. Scientist scores are comparison fields, not inputs to independent scoring.

For data flow, inspect executed final-branch IPython programs and their returned observations.
Separate: reading archived files; incorporating exact old map content; merging all four width-4
pieces; scoped reduction; fresh child reacquisition; and persistent-variable overwrite. Inline text
or file names, scalar agreement, and unexecuted prose/code do not establish use. Never execute model
code, repair answers, or substitute fresh child output for historical state.

Report four P/V cells, within-source contrasts at each opposite-factor level, width/family/context
cluster summaries, counterexamples, and physical versus hypothetical acquisition costs. The 64
endpoints are 16 paired states over four previously exposed contexts, not independent replication.
