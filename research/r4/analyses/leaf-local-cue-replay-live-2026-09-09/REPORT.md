# Current identity cues change conditional label preference

Holding the entire supplied prior output history fixed, changing only the current tag substantially changes the released Qwen3-4B model's label preference. This isolates a local cue effect in this teacher-forced diagnostic; it does not measure attention or demonstrate free-running RLM improvement.

Matching improves the displayed-gold finite-label probability in 14/16 positions in each task. The four AG context-mean differences are +.614, +.657, +.482, +.235; SST differences are +.353, −.059, +.584, +.229. Thus seven of eight context means are positive, not eight. Across all32 positions the descriptive mean difference is +.3869; task-specific results above remain primary for interpretation. Four positions within a context are not independent replications.

The wrong-ID cue often favors the record it names. On the prospectively specified displayed/named-gold disagreement subset (13 AG, seven SST), shifted named-label probability is .6186 / .8409, while displayed-label probability is .0635 / .1591. These are host-derived conditional counterfactual diagnostics, not answers generated by the model. The shifted tag deliberately conflicts with the instruction to classify the displayed position.
