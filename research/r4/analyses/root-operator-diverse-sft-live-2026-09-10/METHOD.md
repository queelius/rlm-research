# Independent audit method: operator-diverse SFT72x6

This method was written after CPU implementation/MAIN acceptance and while MNLI32 occupied the
GPU, but before this sidecar had an `outputs` directory or any capture, gate, optimizer, or
readout artifact. I previously audited the three-policy warm-start reference24 and recommended
the served released-reference857 start as the least-assumption choice; that was not evidence of
superiority. I did not author this SFT implementation, select its examples, or control its GPU.

## Frozen inventory and admission

Reconstruct the 72 planned authored trajectories from `TRAIN_PLAN`, `PUBLIC`, `QUERIES`, and
`GROUPS`: 12 training contexts, three operator/scope queries, widths4/16, four prompt/name
rotations, 180 planned real c32 child acquisitions, 324 root actions. Check training groups are
disjoint from readout04--11 and that host gold cannot enter prompts, child requests, actions, or
targets. Admit training only if all72 authenticated native trajectories are complete. Preserve
wrong child labels and resulting wrong observed scalars; no gold correction, refill, retry,
partial corpus, or success selection. Reconcile every physical root/child request, response,
native token vector, usage field, error, and planned unrun slot.

For every admitted trajectory, reconstruct the executed file load, exact requested record IDs,
typed child result, strict returned map, cumulative live accumulator, and query-sensitive
count/distinct-user/visible-weight reduction. Verify width4 merges all four maps rather than
overwriting with the last variable, and that the terminal answer equals the actually printed
observed scalar. Literal-map or gold-derived shortcuts are not acceptable corpus evidence;
genuine wrong child outputs must remain visible.

## Masks, gate, and optimization

Independently render native histories and verify labels cover only each current assistant action;
all earlier root actions, observations, child tokens, setup and padding are masked. Recompute
producer/reduction/stop token spans and per-trajectory mass (.45 shared across producers,
.50 reduction,.05 stop), including actual token counts. Treat these as objective weights, not
measured gradient shares.

For the six frozen gate examples, recompute full and string/numeric-literal-ablated corrective
mechanism NLLs. Confirm zero gradients/optimizer state before the declared 4/6 >0.1-nat and cost
gate. A passed spending gate establishes nonterminal loss headroom, not learnability.

If training occurs, authenticate fresh AdamW(lr1e-4, weight_decay0), one complete shuffled
72-trajectory pass per update, finite nonzero parameter delta, clipping receipt, and exactly six
committed optimizer increments. For checkpoints1--6, verify Adam step equals ordinal, RNG and
optimizer files, corpus/start identity, previous-state hash chain, and adapter/config hashes.
Checkpoint6 alone is the trained treatment; a partial checkpoint is NULL, not substituted.
Report measured gate, optimizer-only, checkpoint, token-exposure and total stage times separately.

## Fixed readout and interpretation

Reconstruct all48 endpoints: unchanged released-reference857 and fixed SFT6 on the same 24
readout04--11 tasks, one fixed paired seed, three held-out operator/scope cells per context, common
native role/files/c32 child. Verify exact request/task equality modulo root alias and declared
baseline-first phase-order confounding. Score strict final scalar correctness on the planned
denominator by policy, operator, scope/wording, width, context and zero/nonzero gold. A completed
authentic malformed/wrong final is zero. Missing native final, transport failure, loop exhaustion,
or unavailable SFT6 is NULL with bounds; orchestrator completion is not a native final and zero is
never imputed for missingness.

Primary learning evidence is within-task SFT6 minus unchanged paired outcomes, with wins/losses/
ties/NULLs and eight context clusters. Training rows, items, actions, and repeated exposures are
not independent replications. Separately report whether each free trace actually loads records,
calls children, accumulates all returned maps, performs the requested reduction, observes the
scalar, and stops with an authentic final. Ceremonial calls, literal memorization, scalar agreement,
or loss decline alone are not the intended mechanism, though an authentic alternative strategy
can still count as task success and must be described separately.

Report actual physical root/child attempts and returns, known/unknown prompt/cache/output tokens,
stage/owner/outer elapsed time and release evidence. “Paid” legacy fields do not establish billing.
The panel is research- and child-training-exposed; 72x6 versus its unchanged start does not isolate
corpus breadth, repetitions, templates, width, or scope and cannot support broad operator learning.
