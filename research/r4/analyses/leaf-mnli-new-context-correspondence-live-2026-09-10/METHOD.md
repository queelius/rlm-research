## Fixed question and units

Does matching each record's public ID to its requested output tag improve exact-schema displayed NLI
classification versus a repeated constant tag on 16 newly selected context clusters? There are 32
planned endpoints: 16 contexts x matching/constant x one paired seed. Each endpoint contains 48
displayed pairs (16 premise groups x three hypotheses). Context is the paired unit; genre (government,
slate, telephone, travel) is a fixed descriptive stratum. Premises, hypotheses and IDs are identical
within each pair. Items and hypotheses nested within a premise are not independent replicates.

“New context” means absent from the explicitly named original, shifted, exact-tag and bounded exposure
inventories checked by SOURCE_BINDING, not globally research-unseen or pretraining-unseen. Selection
was deterministic and label-blind over the cached validation_matched source after those exclusions.
The same four genres and public MNLI source remain; this is breadth evidence, not a new-domain test.
