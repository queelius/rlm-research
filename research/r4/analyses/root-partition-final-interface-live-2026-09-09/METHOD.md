# Outcome-blind audit method: partition final interface

Frozen before any final-interface outcome existed. The audit independently authenticates every
native response and scores only the complete assistant response as a JSON array of distinct
ascending IDs drawn from `c01` through `c12`. It does not import the scientist's scorer or summary,
extract arrays from prose, sort/deduplicate output, execute tools, or repair answers.

An HTTP-success response becomes available only after verifying the released model alias, unique
assistant choice, exact frozen prompt IDs, integer completion IDs, prompt/completion/total usage,
finish branch, and decoded completion text or parsed tool envelope. A verified tool route or
returned malformed/length output is observed invalid zero. Missing/unrun/transport responses and
inconsistent native envelopes are NULL. The four host gold arrays are independently reconstructed
from the original purchase records still present in each prompt.

Report exact cells for full-report and deduplicated-direct inputs under free/exact decoding,
12 within-input pairs, eight full states, four direct worlds and four world clusters. Preserve
world dependence: the colocated/cross full states share four engineered worlds. Recount physical
new final calls, zero new extraction calls, 24 unique historical extraction paths, and the 48
hypothetical acquisitions charged across 16 full endpoints. Compare scientist scores only as a
post-hoc disagreement check.

Interpretation is narrow. Exact-minus-free isolates the decoder interface under the new common
vLLM service/cap. Full-versus-direct is descriptive because prompt contents differ. Original records
remain visible, so failure is not evidence of communication loss. Four engineered worlds do not
support a broad generalization claim.
