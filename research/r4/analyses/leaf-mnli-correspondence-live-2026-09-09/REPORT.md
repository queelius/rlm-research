## Decision

This clean final-only/no-tool NLI condition rules out “irrelevant coding role/tools alone explain the observed constant-tag failures” for this panel. Shape grammar fixes constant-tag cardinality here but does **not** close the label gap. Matching correspondence is therefore useful beyond simply making a JSON array parseable; the evidence is consistent with tracking/alignment benefits, not a direct proof of internal reasoning improvement. Preserve strict ID checks: generic grammar still permits a whole-contract matching-ID failure. A next bounded confirmation could use a frozen same-type source-ID interface in a genuinely new context panel/whole-RLM leaf route, while retaining exact correspondence scoring and matched grammar. No larger model, training acquisition or relaxed old rewards follows automatically.
