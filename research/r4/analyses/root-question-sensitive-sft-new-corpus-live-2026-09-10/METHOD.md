# Question and timing

Does the six-update question-sensitive SFT result recur when all 72 teacher trajectories are rebuilt
from a newly selected TREC-train corpus, with the same fixed24 root start and c32 child but a fresh
optimizer? The evaluation is the already research-exposed metadata72 panel. This is an independent
training-corpus realization, not an independent evaluation panel.

# Decision boundary

A positive exact score alone is insufficient. The replication is persuasive only if it improves
grounded, actually-performed nonzero composed answers relative to the reused start and shows the same
direction as original QS6 across multiple context clusters without an availability loss. A flat or
negative result lowers confidence in the single-realization SFT claim; it does not establish that SFT
or question-sensitive supervision is generally ineffective.
