# Terminal-only audit implementation

The sealed METHOD.md is authoritative and remains unchanged. New code lives only
here; no experiment imports that launch or collect, no live outcome reads during
preparation, and no polling. Parent supplies the terminal trigger.

1. Fixture-first pure projections for conservative unknowns, duplicate claim
   retention, paired missingness, terminal categories and physical cache usage.
2. Read retained operator-authored qualification traces; independently verify
   sampled graph/wire prefixes, action tokens, probabilities, roles and seeds.
3. Implement one-pass terminal artifact projection, reusing the sealed 332-path
   authentication cache and hashing each newly encountered artifact once.
4. On parent trigger only, publish preliminary metrics immediately, then readable
   report, detailed evidence, source inventory and final seal. Human review of
   candidate incorporation evidence remains separate from automatic AST markers.

The external analysis namespace is the requested isolation; no Git worktree,
installation, service, signal or GPU operation is appropriate for this task.
