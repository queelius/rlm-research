# Independent audit method: positional-anchor MNLI96

This method was written after MAIN launched the accepted attempt at epoch
`1789065686.2733543`, but before this reviewer opened any scientific output,
terminal record, response, producer summary, or score. A path-only inventory
made while locating sources showed that an `OWNER_TERMINAL.json` filename
already existed; its contents and all outcome files remained unread. This is
therefore a post-launch, outcome-unread method freeze, not a preregistration.
The reviewer authored this study's implementation and earlier correspondence
controls, so the audit is reproducible and raw-native but not author-independent.

## Frozen inventory and primary estimand

Audit all 96 planned coordinates: 8 research-exposed contexts crossed with
visible reference (`wrong`, `alien`, `aligned`), input row field
(`absent`, `present`), and output form (`labels_only`, `row_first`). Preserve
the paired seed within each 12-arm context block, actual rotated dispatch, and
all unavailable endpoints. No rerun, reordering, partial-array extraction,
label repair, or replacement by producer summaries.

The primary contrast is, at input-row absent, row-first minus labels-only late
position (17--48) accuracy, summed over the three reference arms within each
context and averaged over eight paired context clusters. Report the aggregate
point difference over 768 late labels, the eight context differences and sign
count, joint availability, and NULL-aware bounds. The prospective operational
promotion threshold is at least 10 percentage points, positive in at least
6/8 contexts, with no loss of call availability. It is a pilot decision rule,
not equivalence or mechanism proof.

Also report total and first-16 accuracy; input-row simple effects within each
reference/output cell; output-anchor effects with input rows present; the
wrong-versus-aligned interaction; genre/context tables; exact row-token
fidelity; shape validity; and whole-contract validity. A larger present-row
effect is mechanism evidence but is not required to advance an output-only
anchor. Input-only gain is separately actionable. The package changes
instructions, schema, and generated tokens, and an emitted row can steer the
next label, so no pure-attention claim is allowed.

## Native admission and semantic scoring

Re-render each accepted request from frozen inputs. Verify the complete native
request body and expected prompt-token IDs against the recorded request; exact
released Qwen3-4B alias/path, no adapter/tools/thinking; sampling and token
caps; unique assistant choice; native completion text/token correspondence;
usage and finish branch. Inspect service binding and release separately.

An authenticated completed malformed or wrong-route response is observed zero,
not infrastructure NULL. An absent response, HTTP/provider failure, incoherent
native envelope, missing unique choice, or unauthenticated final is NULL with
[0,48] bounds. Labels-only requires exactly 48 canonical labels. Row-first
requires exactly 48 objects, unique keys in exact `row`,`label` order, rows
0--47 in position, and canonical labels. Wrong row values, duplicate keys,
field-order violations and incomplete arrays are whole-contract failures;
never reorder or salvage their labels. Score displayed-record MNLI gold only.

## Physical cost, closure, and limitations

Union all REQUEST/RESPONSE/RESULT and service artifacts, including unexpected
directories. Distinguish unstarted, request-recorded, response-proven attempt,
HTTP success/failure, choice-bearing completion, native-authenticated final,
contract-valid final, and observed invalid zero. Preserve per-field known and
unknown input/output/cache usage and finish/length/error causes; do not infer
provider billing. Report exact owner/parent timing and release proof when MAIN
relays closure.

Eight contexts, one seed per context, reused source records, post-hoc-motivated
late split, arm-order imbalance, and within-context label dependence prohibit
record-level independence or confirmatory novelty claims. Final reporting must
retain counterevidence and make the distinction between output-position help,
input-row help, availability, and semantic correctness explicit.
