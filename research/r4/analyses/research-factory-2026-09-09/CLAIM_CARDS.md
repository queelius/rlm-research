# Three candidate claim cards

Exact denominators, source hashes, alternatives and links are in [CATALOG.json](CATALOG.json). These are exploratory publication questions, not publication declarations.

## 1. Output-source correspondence — promising component result

**Fact.** Matching IDs beat constants in all16 task/model/context means on bounded new AG/SST records across released Qwen3 and Qwen3.5. Gains are167–245 labels per512 presentations;96/96 calls are available/schema-valid. [Fresh96](../leaf-fresh-correspondence-live-2026-09-09/REPORT.md).

**Mechanism-narrowing evidence.** Shifted grammar-provided IDs pull labels toward named records despite positional instructions. Phase rotation over the same61 records produces positive distance0-minus3 effects in all12 exposed context clusters. [Shifted72](../leaf-shifted-cue-live-2026-09-09/REPORT.md), [phase192](../reminder-phase-live-2026-09-09/REPORT.md). Named alignment never replaces the positional primary.

**Contrary evidence.** Bridge32 improves matched count-label agreement567→593/628 but count remains1/8 and checksum0/8. Checksum paired uptake is3/8; child widths mostly4, never64. [Bridge32](../root-child-representation-bridge-live-2026-09-09/REPORT.md).

**Inference boundary.** This favors source correspondence beyond varying-token novelty, not hidden attention proof, freely learned ID retrieval, equal realized compute or general recursion benefit. New records have bounded exclusions; phrase/near-duplicate/pretraining exposure and dataset licenses remain unresolved.

**Next decision.** Finish separately authorized fixed-root bridge policy tests. Promote whole-RLM usefulness only with whole-task gains under adequate actual exposure; revise toward uptake/reduction bottlenecks if labels improve without answers. Status: promising, not confirmatory-ready.

## 2. Limited controller-training gains — exploratory

**Fact.** Fixed8 higher-LR success-SFT improves frozen8/24→14/24, largely length1/8→6/8. Four native root-RL updates improve7/24→11/24; availability-safe net[3,4]. These are one training realization and eight exposed context clusters, not independent training replication. [SFT-LR](../root-success-sft-lr-live-2026-09-09/REPORT.md), [RL](../root-bounded-refill-rl-live-2026-09-09/REPORT.md).

**Negative control.** Authored canonical/filter-first SFT4 yields1/16 each and is worse than unchanged while increasing exhaustive classification. [Plan-SFT](../root-plan-sft-live-2026-09-09/REPORT.md). Syntax/coverage recovery is not transferred query planning; jointly successful cases show no universal compute saving.

**Additive correction.** Later query audit finds one low-LR broker error, not a sampled empty final. Preserve original0 and report query net bounds[-1,0]. RL and plan also separate unavailable branches. Never pool different doses or silently overwrite their endpoint rules.

**Diagnosis.** All19 displayed integers in32 reused query trajectories are copied faithfully. Six cases have a correct map but no executed count;15 reuse one dataset-label disagreement. Bridge’s selected program reduces its final batch instead of accumulated labels, then faithfully reports the wrong scalar. This is not an observed correct-scalar-copy defect. [Taxonomy](../root-query-failure-taxonomy-2026-09-09/REPORT.md).

**Next decision.** Prioritize approved new-panel supplied-map/executed-reducer and complete-procedure teaching, with no gold repair, forced plans or automatic submission. Promote only new-composition query gains with native likelihood/masks, real optimizer steps, availability and total costs intact. Status: exploratory.

## 3. Sufficient recursive information — proposed, no result

**Hypothesis.** Learned intermediate information can preserve correct global composition across valid partitions and unseen query/structure combinations. User ideas1+5 rank highest among broader families; idea3 supplies representation transformation. [User ideas](https://github.com/queelius/rlm/blob/83cd0269da9774aa2280cc3d3f462178ea894bf9/new-ideas/ideas.md) remain read-only.

**Critical limitation.** Full incidence beating deliberately lossy local-winner reports is true by construction: a diagnostic/control, not a learned contract or itself a publishable discovery. Include ordinary unconstrained child reports. Valid citations do not prove complete extraction; a constant wrong answer can be perfectly invariant.

**Small proposed pilot.** Four48-record worlds, two valid3×16 partitions each, colocating versus splitting customer A/B purchases without changing the answer. Compare ordinary reports, the explicit lossy negative control and incidence/evidence. One illustrative updated budget is88 physical calls:24 incidence workers shared between two declared projections,24 ordinary workers,24 parent continuations,16 matched full-input direct/synthesis calls; four CPU exact-program baselines are operator-authored. Charge shared worker acquisition fully to each logical pipeline. This extends the earlier56-call sketch to include ordinary reports; no input/seed/runtime plan is frozen or accepted.

**Boundaries.** Keep original input accessible to the free parent. Report-only counterfactuals are separate information-sufficiency diagnostics, not whole RLM. Freeze label-independent generation, held-out query×structure×linguistic templates, input length/call/output budgets and measured total cost. Partition robustness is not depth generalization. Later learned report choice must beat fixed interfaces on unseen combinations before claiming learned sufficiency; exact nonrecursive code may explain all gains.

**Prior/contrary evidence.** Typed maps and narrow first-action teaching have not solved whole-task composition. [RLM v3](https://arxiv.org/abs/2512.24601v3), [λ-RLM](https://arxiv.org/abs/2603.20105v1) and [Chained RLM](https://arxiv.org/abs/2608.05124) are MAIN-verified primary references, not novelty clearance. The [named counterfactual citation](https://openreview.net/forum?id=k2NrIxm4Do) is unverified.

**Priority.** After, not instead of, the smaller approved supplied-map/reducer diagnostic. The tentative single-A1001800s cap is a feasibility estimate, not measured throughput. Continuation state (idea6) stays separate; resumable children/counterfactual credit/latent recurrence (2/4/7) are deferred. Status: exploratory hypothesis, no result.
