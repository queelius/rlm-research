## Separate the metrics

1. **Local reporting:** classify each of the 24 planned worker responses as malformed, invalid claim, claim-valid but wrong, exact, or unavailable. Exact report correctness requires the complete eligible relation. Record row omission/addition and effective-field errors separately when available.
2. **Report-implied sufficiency:** among the 32 planned recombinations, preserve unsupported tuples explicitly. For a claim-valid tuple, compare the deterministic combiner's result with source truth. This measures whether the displayed claims imply the true optimum, not whether all local reports are exact.
3. **Root synthesis:** primary true-source exactness uses `grade_root_response(text, root)`; separately record `grade_root_response(text, root, displayed_reports)` as report consistency. A correct root can repair or ignore a wrong advisory report. For all 12 selected-row omission controls, source gold is source-correct but invalid against the omitted displayed relation.
4. **Root-specific contrast:** report which of the four roots has both sufficient and insufficient report tuples, and separately which has both successful and unsuccessful actual synthesis outputs. Eight tuples from one root are not eight independent task units.
5. **Controls and cost:** retain four direct-source calls and four nondeployable exact-report-oracle calls. Report actual physical calls/tokens including errors separately from per-policy reuse accounting. Invalid worker output is not repaired; its dependent tuples are unsupported, not silently counted as successful/failed model generations.

Exact local completeness is stronger than global sufficiency: retaining only each stage's local capacity/quality winner makes every local report incomplete, yet the resulting reports still imply the true root optimum on 2/4 active roots. Therefore a locally wrong report need not be globally harmful, and local correctness alone is not an adequate selector target.

Correct synthesis on an insufficient report tuple is consistent with source repair or reports being ignored; success alone cannot distinguish them.

Each recombination receives a different synthesis seed. Deterministic combiner contrast is caused by report changes, but actual model reward contrast also contains decoding variation. Do not claim isolated report-tuple counterfactual causality.
