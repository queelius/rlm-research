## Important interpretation limits, not blockers

Cumulative return changes the set of keys beyond the current requested IDs. A legal batch-running-total program can double-count old labels; a print of each returned map can inflate context. Both risks are explicit in the prompt/design and must remain observed model failures/costs, not be fixed after launch. Common hidden accumulation and ledger state are accessible through Python introspection; control uptake of that state is an alternative mechanism, not evidence that batch-local returns retained it. Module reload/tampering is not silently repaired.

Promotion requires demonstrated multi-batch coexisting state used in an actual requested computation, separately from dataset correctness and consistency with fallible child labels. Do not host-union maps the model never retained, count structural acceptance as genuine acquisition, or call literal recovery verified live accumulation. Four parent clusters remain the meaningful grouping;16 pairs are not independent source worlds.
