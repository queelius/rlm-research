This implements the already sealed METHOD, without opening live outcomes. The
14 focused tests use synthetic failures plus the frozen eight-call, operator-authored
native CPU qualification. They do not run a container, provider, model or GPU.
Graph roles, physical prefix versus causal ancestry, partial-work attribution,
multiple request matches, null pairing and no pre-trigger reads are covered.

Only after the parent explicitly reports the terminal handoff:

```bash
CUDA_VISIBLE_DEVICES='' PYTHONDONTWRITEBYTECODE=1 /project/alex_phd/envs/prime-rl-5990b1b/bin/python /project/alex_phd/runs/rlm-research-r4/analyses/child-role-suffix-live-2026-09-09/audit.py --after-parent-terminal
```

The command checks the accepted child's EXIT and recorded empty GPU, authenticates
completion markers and release evidence, then reads raw artifacts once. It never
queries processes/GPU, takes scheduling locks, retries, repairs answers, or invokes
the scientific driver. Missing setup markers are operational evidence; an absent
EXIT is a readiness error before raw outcomes are opened. No polling is built in.

The frozen 271-file closure is authenticated once and reused through an evidence
cache, including new bindings. Credential-bearing service config/log bytes are
hashed but not copied into projections. The 16-coordinate grid is retained, and
request IDs map to candidate lists rather than overwriting duplicate matches.
Returned native sampling, HTTP responses, allowed hooks, prevented hooks and
unknown delivery are different denominators. Role metadata is corroborated with
the qualified overlay, binding and native ancestry; prose is not authority.

`METRICS.json` materializes raw-source pointers, physical accounting, graph and
invocation evidence, strict parser comparison, eight pairs, four context summaries,
known/unknown costs and lifecycle times. `SOURCES.json` authenticates raw inputs.
Both are write-once; rerunning refuses to silently rescore existing projections.
Then write `REPORT.md` and a final publication seal from those saved projections.
Child-request conflict and off-task behavior still need bounded reading of the
recorded requests/code/observations; lexical screens are not semantic verdicts.
Built-in READOUT, if present, is retained for reconciliation, never treated as truth.

No fresh performance evidence or stronger generalization claim is licensed by
this preparation. Scientific outputs, source, METHOD and queues remain untouched.
