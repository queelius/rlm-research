# Independent flexible-four allocation readout

This CPU-only analyzer waits for nothing and makes no model calls. MAIN runs `CUDA_VISIBLE_DEVICES='' PYTHONDONTWRITEBYTECODE=1 /project/alex_phd/envs/prime-rl-5990b1b/bin/python analyze.py` after the fixed owner terminal is saved. It refuses a missing terminal and existing outcome directory. Preparation makes only one pending-state check, then stops until follow-up.

The accepted source READY is pinned. The previously reviewed independent native-token/answer/support scorer is reused without calling its old experiment runner. The new graph is reconstructed independently from decoded ranked selector and planner IDs: exact four unique IDs per half, exactly four candidates selected by the planner, fixed first2+2, sorted original final source objects, unchanged final instruction and paired seed. Every observed prompt is locally re-rendered and matched to actual native input tokens. The source owner’s decoder flags and scalar scores are not accepted without raw reconstruction.

All12 exposed contexts remain in the denominator. Native invalid/unknown calls stay unknown; invalid model selectors empty both arms, invalid model planner empties only flexible, and a valid fixed result remains available. The result retains observed final diagnostics when a natural dependency is unknown.

Record60 physical calls, natural fixed36/flexible48 costs, observed prompt/completion/cache tokens and unknown counts. Four final paragraphs are matched on valid rows, not token length or natural call count. Paired wins mean fixed-wrong→flexible-correct. Do not reuse the earlier fixed2+2 score.

Host-only diagnostics distinguish candidate-pool coverage from final selected coverage, actual half allocations and structural fixed2+2 limits. MECHANISM_EVIDENCE.json preserves all12 candidate pools, selected exact sources, gold component questions/answers/support paragraphs and raw finals for inert relation-level adjudication after completion. Coverage is neither necessary nor sufficient for a correct requested relation; specific alternative support, wrong-entity copying, verbosity and annotation problems require reading actual evidence. No generated code is executed, and no gold enters model prompts or allocation.

This tests actual model routing at a fixed final paragraph budget on an exposed panel. It does not establish learned routing, recursion, novel methods, or confirmatory transfer. No automatic winner promotion or next run is authorized by this analyzer.
