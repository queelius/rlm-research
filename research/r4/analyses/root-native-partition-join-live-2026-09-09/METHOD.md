# Native partition-join independent audit method

Timing: frozen after the job had already completed and released, and before this auditor read any
row score, summary, acquisition outcome, native completion, or cost value. The auditor had observed
only that terminal/status and expected output filenames existed. This is a source-informed,
outcome-blind scoring closure, not a prospective preregistration.

Frozen inventory: 48 planned endpoints = three representations (direct originals, co-located
reports, cross-partition reports) × Python advertised/absent × four generated worlds × two paired
seeds. Twenty-four shared report-extraction calls are separately planned. Worlds, gold, plan,
prompts, native tool inventory, source, and READY closure are hashed before outcome inspection.

Audit rules:

1. Recompute every world answer from frozen original records. Independently parse each acquisition
   as an exact complete triple array; no repair. A report endpoint is source-available only if all
   three corresponding actual extractions are exact. Direct endpoints do not depend on acquisition.
2. Strictly score only the complete authenticated terminal assistant content as a sorted, unique,
   in-domain JSON customer array. Returned malformed/capped/no-final policy traces score zero for
   operational success; infrastructure, source-gated, and unrun endpoints remain NULL with bounds.
3. Authenticate actual model alias, tool inventory, first native prefix, wire request/response,
   completion tokens, final branch, finish route, and complete 48-slot inventory. An unadvertised
   tool attempt is a policy failure, never executed or relabeled as infrastructure.
4. Inspect generated programs and observations as text only. Credit actual aggregation only for
   input-dependent computation across records/chunks with an observed result. Separate root-only
   aggregation, subordinate child assistance, file access alone, literal printing, and direct prose.
5. Report paired Python-present/absent and representation contrasts by world/seed, treating four
   worlds as the independent clusters. Report exact physical attempts/returned usage and the 24
   shared acquisitions separately from hypothetical standalone pipeline charges. Billing/cache
   remain unknown unless native evidence provides them.
