# Supplied-plan ceiling native audit method

After exact terminal authorization, reconcile all forty frozen request bodies
and byte hashes, then authenticate model, unique native choice, completion IDs
and logprobs, usage, finish branch, and renderer output. Independently rescore
each whole 32-record ID map. An authenticated malformed/wrong-route map is an
observed policy failure; an absent or incoherent native response is NULL. Never
repair, reorder, or partially salvage a map.

For each of the eight episodes, recompute the deterministic public J1 reducer
from public records and the complete predicted map only. A complete valid map
may still produce a wrong scalar and is then an observed strict failure. If any
batch is malformed, the episode is observed invalid with unknown predicted
scalar; if any batch is infrastructure/native unavailable, the episode is NULL.

Separately run the same reducer with private host labels as an audit oracle and
verify it reproduces frozen host gold. Report predicted-versus-oracle qualifying
users, per-record contribution errors, map coverage, leaf-label correctness,
absolute scalar error, exact final correctness, size and cluster strata, NULL
bounds, and the complete physical/cost union with per-field usage unknowns.

The supplied reducer is experimenter-authored. Its correctness is not learned
planning or root-model competence, and the child-only ceiling is not compute
matched to free-root studies. This reviewer authored both producer and reader;
the audit is prospective and raw/native, but not author-independent.
