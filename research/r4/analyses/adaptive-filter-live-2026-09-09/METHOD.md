## Decision rules and publication

Publish raw ledger, independent endpoint/physical-cost reconstruction, reconciled
author discrepancies, bounded source manifest and concise REPORT. Include all
four context outcomes and failure accounting, not only aggregate favorable rates.
Any unforeseen mechanism diagnostic gets a separate dated post-hoc note.

If operator filtering retains adequate observed success/coverage and lowers
physical cost, it demonstrates an available policy opportunity, not learned
adaptation. If free behavior visibly changes its selection with the question
and approaches this opportunity, pursue independent query/length compositions.
If free fails the new interface while operator succeeds, prioritize a separately
declared interface-only warm start before planner training. If both fixed policies
answer correctly, accuracy-only sparse rewards may not favor efficiency; a
cost-aware reward is a new experiment, not a post-hoc reward revision.
If strict child maps or installation dominate failure, report interface/operations
feasibility first and address that bounded cause. Do not call an unconsumed
helper/receipt treatment ineffective. Preserve competing direct-root strategies.
