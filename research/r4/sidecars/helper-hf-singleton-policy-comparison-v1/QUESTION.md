# Singleton inference-shape transfer

Question: on the exact research-exposed fixed256 panel and its already frozen singleton request
schedule, does the completed reference T1/LR1e-5 checkpoint-0004 outperform the original c32 helper?

This tests whether the singleton-map serving shape used during true-HF RL training exposes changes
that the published four-record evaluation can hide. It is an adaptive panel-by-request-shape
interaction check, not confirmatory generalization. Both arms use byte-identical prompts, schemas,
temperature-zero sampling inputs, coordinate seeds, and ordering. Only the authenticated child
adapter binding changes. Each arm starts and releases its own fresh service.

Primary metric: paired record-level correct/wrong/unavailable endpoints by dataset. Secondary
metrics: label transitions and physical calls, prompt/completion/cache tokens, and wall time. The
old size-1 c32 score and old size-4 c32/reference scores are context only; they are not pooled with
these fresh services.
