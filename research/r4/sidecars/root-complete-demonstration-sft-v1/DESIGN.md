## Capture before optimization

The16 exact canonical targets from root-plan-sft-v1 are executed once each inside
the qualified owned native IPython runtime. The root endpoint supplies the authored
tool action, while every child request is forwarded to the actual c32 service.
The second root request must contain exactly one actual scalar tool observation.
The terminal target is Answer: that scalar, even if it disagrees with dataset gold.
The graph-rendered second prefix must match the actual native wire IDs. All prior
actions, observations and child tokens are masked; only current targets have CE.

Transport root responses include explicitly synthetic zero logprobs because the
native transport requires them. These are NOT sampled behavior probabilities;
their raw traces are named AUTHORED_NOT_RL and cannot be an RL export. Neither
training row contains likelihood/reward/admission fields. The native fixture task
has a dummy host verifier answer solely to run the task; its reward is NOT training
data and never selects examples. Real child responses and raw requests are retained.
All16 must yield authentic scalars; otherwise stop and preserve partial capture,
without reroll, omission, fabricated observations or optimization. A separate
CORPUS_READY freezes actual rows/provenance before either training process starts.

or replacement is added, and physical attempts remain explicit.
