# Released-base leaf role/tool contract screen

Question: does removing the inherited coding-agent/tool interface restore usable free long-batch
classification, or is failure specific to output representation? This exploratory 96-call screen
crosses coding versus final-only classifier system, IPython advertised versus absent, matching-ID
objects versus constant-tag objects versus plain labels, and free versus exact decoding on two new
64-record AG News contexts and two new 64-record SST-2 train text-unit contexts. One sampling seed
is paired across every condition.

Primary reporting is free-decoder full-contract-valid strict positional label accuracy on the
planned denominator. Completed malformed, capped, code, wrapper, or native-tool-call outputs are
observed policy failures worth zero; only infrastructure-missing calls are NULL with bounds. Native
tool calls, literal wrappers, code/prose, finish reason, tag/order diagnostics and conditional label
accuracy remain separate. No generated tool call or code is executed, and IDs never reorder or
repair predictions. System-role replacement is a package contrast; tool advertisement is the
separate within-system factor. Four context clusters and one seed support exploration, not a
confirmatory generalization claim.
