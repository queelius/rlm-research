# READY V3 correction

A second independent review found that V2 still inferred probe costs only from `RESULT.json` and
used ambiguous completion names. V3 inventories the probe `REQUEST`/`RESPONSE`/`RESULT`/`FAILURE`
disk union. A response proves a physical attempt; a request without response or result is explicitly
prepared/attempt-unknown. Raw choice-bearing responses, HTTP responses, endpoint native finals, and
usage are separate. The free ledger calls choice-bearing physical responses raw returned choices;
it does not claim to authenticate each model call. Missing-result answers remain NULL and are never
recovered or synthesized.

V1 and V2 remain as rejected pre-review history. Scientific inputs and caps are unchanged.
