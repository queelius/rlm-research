# Did the fixed selection update learn rules or original identifier strings?

This exploratory readout renames every implementation ID in the nine original training stages with
one deterministic, outcome-blind bijection. All numeric values, policies, histories, check results,
root/stage identities, paired seeds, endpoint weights, and grading rules remain fixed. It compares
the released base and the sole fixed cp1 checkpoint over 18 decodes each.

A retained cp1 advantage would be consistent with learning beyond the literal old names. Its loss
would motivate testing representation diversity before another learning-rate sweep, but would not
prove memorization because renaming also changes tokenization and stochastic continuations. This is
an in-sample mechanism probe, not a generalization or pure causal claim.
