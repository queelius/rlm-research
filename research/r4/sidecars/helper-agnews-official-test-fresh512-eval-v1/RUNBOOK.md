Run each READY command separately under MAIN's shared GPU lock and private credential
environment. Each owner has a 900-second internal cap and 1000-second external cap.
The four checkpoint identities were fixed before any query on these 512 records and
must all be reported; seed-2 is a replication arm, not a selected winner.

After all terminals, run `compare.py` CPU-only with CUDA hidden. This is locally new
same-task/source-test evidence, not a new domain and not evidence of absence from base
pretraining. Training-input manifests and the evaluation DATA_READY are separate pins.
