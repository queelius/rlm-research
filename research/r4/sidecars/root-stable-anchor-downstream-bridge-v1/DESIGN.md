# Stable-anchor downstream bridge

This implements the frozen design in `ideas/2026-09-10-stable-anchor-downstream-bridge.md` after
opaque passed the predeclared upstream gate. It makes 16 fixed leaf acquisitions (eight contexts by
sequential versus opaque keys), then 64 root episodes crossing two varied questions and supplied
versus free root policy. Both encodings are normalized to the identical `classify_all()` public-map
contract before the root runs. Maps are shared across four correlated root cells and charged once.

The exact deterministic panel failed only the original answer-frequency cap: count answer 3 occurs
4/8 times. Before model output, MAIN approved an additive cap change from 3 to 4 without reranking,
resampling, or changing any threshold. The original failure receipt and amendment are preserved.
Correct-and-faithfully-performed remains primary, so constant coincidences do not pass.

One A100, four workers, 1,800 seconds outer / 1,770 owned / 1,650 work, 90 seconds per request,
3,072 leaf and 2,048 root output-token caps. No retry, fallback, repair, training, or GPU launch is
authorized by this package.
