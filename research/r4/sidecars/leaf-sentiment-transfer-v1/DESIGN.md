# SST-2 task transfer: frozen prospective design

Question: do mixed-size TREC LoRA curricula improve long-batch correspondence on a different task and output vocabulary, or only the six trained TREC labels?

No training. Use only the public labelled SST-2 validation split at official Stanford NLP Hugging Face dataset revision `8d51e7e4887a4caaa95b3fbebbf53c0490b58bbb`. Before downloading the rows, fix normalization as Unicode NFKC, casefold, whitespace collapse; group SHA256 of normalized UTF-8. Sort all unique groups lexicographically by this hash, take first256 without labels influencing ordering/filtering; representative is lowest physical row index, retain every original idx/physical index and any label conflicts. Four contiguous64-group contexts in hash order. Preserve original representative sentence bytes in prompts. No train/test downloads, training-corpus changes or checkpoint selection from sentiment outcomes. Public evaluation data may already occur in base-model pretraining or historical tuning; overlap unknown.

Models: exact converted original LoRA857a7ce6..., old validation-selected fixed5 SFTc32de129..., mixed A fixed final epoch2, mixed B fixed final epoch2. Primary measures: strict whole64 success (all required arrays exact canonical JSON and all64 correct), full-array contract coverage, canonical item accuracy counting unavailable/misaligned items incorrect, and position quartiles1–16/17–32/33–48/49–64. No alias normalization, truncation, majority voting or fallback in primary score. Four contexts/256 groups are the evidence units; seed repeats are not independent data.
