calls the recovery builder and then tries to write the same CORPUS_READY file
again. The writer is exclusive-create. V4 therefore cannot reach training even
when its seven genuine acquisitions finish. Preserve that failure and every
capture; do not change the live owner, resample teachers or overwrite receipts.

The training-only owner may start only after V4 is terminal and released,
all 72 fixed teachers pass the existing V3 corpus verifier, and neither the
original nor V4 attempt contains a training directory. It uses a new output
namespace, outputs/attempt-002, while the verified corpus remains under the
original and recovery attempt-001 directories. The coherent V3 science identity
is retained. An additive owner amendment and parent acceptance pin the new code.

No task, seed, example, model, optimizer, gate, six-update selection rule or
evaluation question changes. The original baseline80 is reused exactly once;
only fixed6 dev8/protected72 is collected. The readout service-local deadline
and per-field known/unknown accounting remain as qualified in V4.

readout2100 and finalization420, plus150 cleanup and30 outer margin. The owner
checks original parent execution + V4 parent execution +4800 against the
combined10800-second active ceiling. Calendar idleness is separately charged

rerun, missing-checkpoint substitution or outcome-based selection is permitted.

This is an operational continuation, not another experimental treatment.
